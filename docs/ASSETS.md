# Original assets

All game art and audio are generated by `tools/generate_assets.py` using a fixed random seed (71), simple pixel silhouettes, a muted palette and synthesized waveforms. No third-party game sprites, fonts or songs were copied. UI uses Godot's bundled default font.

Terrain: 16×16 RGBA PNG. Actors/props: 32×32 RGBA PNG with transparent surroundings, centered origin, feet near the bottom; player and enemies draw at 1.5×, boss at 3×. Village house: 64×48. Current sprites are one frame with procedural bobbing and horizontal facing. Replacement artwork should preserve file paths and dimensions until sprite-sheet animation is introduced. Planned animation names: idle, walk, attack, hurt, dodge, death, each with four directions and at least four frames; these are conventions for future work, not implemented animations.

Nearest texture sampling is enabled in project settings. PNG and WAV `.import` metadata generated by Godot is retained. WAV assets are mono signed 16-bit PCM, 22,050 Hz; `music.wav` is an original eight-second minor-key motif and `ambient.wav` a four-second drone. WAV loops are enabled at runtime. SFX use short synthesized envelopes. Runtime settings control master, music, SFX and ambient volumes. Headless and Dummy-audio QA skip continuous audio playback to avoid dummy-driver shutdown resource warnings. Actual CoreAudio output needs a Mac listening pass.
